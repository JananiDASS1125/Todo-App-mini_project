#Todo List Management App
A simple Todo Management application build using the MERN Stack(Mongodb,Express.js,React.js,Node.js)
#Features
1.User Registration & Login
2.JWT autentication
3.Create,Update and Delete todo lists

#Teck Stack
Mongodb
Express.js
React.js
Node.js
Mongoose

#Backend
cd backend
npm install
npm start

#Frontend
cd frontend
npm install
npm start
